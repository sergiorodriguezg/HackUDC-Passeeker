# Changelog

Todos los cambios relevantes de este proyecto se documentarán en este archivo.

El formato está basado en “Keep a Changelog” y el versionado sigue el esquema Semantic Versioning.

---
## [1.0.0] - 29/02/2026
### Added
- Aplicación de escritorio desarrollada con Electron.
- Servidor API local mediante Express.
- Sistema de autenticación con usuario y contraseña maestra.
- Derivación de clave mediante scrypt.
- Cifrado de contraseñas con AES-256-GCM.
- Sistema de sesión con token.
- Integración con Have I Been Pwned API (modelo k-anonymity).
- Generador de contraseñas mediante Random.org.
- Fallback criptográfico local con Web Crypto API.
- Sistema de emparejamiento con extensión de navegador.
- Indicadores visuales de estado de seguridad (pwned / no pwned).
- Interfaz gráfica completa (gestión, edición y eliminación de credenciales).
